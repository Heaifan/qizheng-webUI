# 奇正相生 MVP v0.3

本版重点修复：可见网格加密、按格自动填充、拖动画笔不断格。

## 运行

双击 `run-local.bat`，浏览器打开：

```text
http://127.0.0.1:8080
```

## 地图参数

- 地图：320 × 512 = 163840 格
- 单格显示尺寸：4px
- 每个格子只存一个地形 ID
- 画笔经过某格时，整格会被当前地形覆盖

## 操作

- 选择地形后，在地图上拖动即可画地形
- “画笔 - / 画笔 +”调整按格填充范围
- “模式：画笔”切换到拖图模式
- “清空”恢复草地

## 项目线

本目录是奇正相生**新版本线**：纯 HTML / 原生 JS / Canvas 地貌编辑器原型。
旧版本线（Vue / Pinia / Electron / TypeScript 战斗原型）位于 `qi-zheng-interplay` 仓库，请勿混淆。
